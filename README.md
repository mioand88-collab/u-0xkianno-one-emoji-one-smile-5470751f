## The emoji

🤗 — the hugging face. I weighed the obvious candidates and picked this one deliberately: 🫶 (heart hands) risks reading as intimate or romantic from a stranger; 🌻 (sunflower) is sunny and universal but says "cheerful" more than "friendly to you"; 🥹 (holding back tears) is tender but can read as sad or overwhelmed. The hugging face is a warm, open-armed welcome that needs no context, is understood the same way by any age or background, feels chosen rather than the default 🙂/😊, and offers a friendly virtual hug — warm, never flirtatious or sarcastic — exactly the kind of thing that makes a stranger smile.

## How to run

```sh
node main.ts
```

This writes exactly one emoji, 🤗, to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program guards that the entry is a single emoji of 1–8 characters before writing.
